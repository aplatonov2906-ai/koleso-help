# Koleso.Help — сайт-визитка выездного шиномонтажа

Вёрстка по макету Figma «Koleso.Help» (файл `Koleso.Help.fig`).
Чистые HTML + CSS + JS, без сборщиков — открывается двойным кликом
по `index.html` или через `start.cmd`.

## Страницы

- `index.html` — Главная (фрейм 106:1400)
- `gruzovoy.html` — Грузовой выездной шиномонтаж (фрейм 95:673)
- `shiny.html` — Ремонт повреждений шин / легковой (фрейм 106:1103)

## Структура

```
koleso-help/
├── index.html
├── css/style.css      (один общий файл, мобильная адаптация внутри)
├── js/script.js       (маска телефона + отправка формы)
├── images/            (ассеты, выгружены из .fig и сжаты под веб)
└── start.cmd
```

## Заметки

- **Шрифт.** В макете Gilroy (коммерческий). Подключён Montserrat с Google
  Fonts как ближайший бесплатный аналог. Если появится лицензия Gilroy —
  положить woff2 в `fonts/`, прописать `@font-face` и поменять `--font`
  в `css/style.css`.
- **Форма заявки.** Бэкенда пока нет: JS показывает подтверждение и пишет
  данные в консоль. Точка подключения — `js/script.js`, закомментированный
  `fetch` (можно направить на вебхук CRM `/api/intake`).
- **Телефоны/ссылки** взяты из макета (заглушки дизайнера: +7 495 110 22-22,
  +7 499 999 99-99, info@ya.ru, адрес ТЦ Metromall) — заменить на реальные
  при запуске.
